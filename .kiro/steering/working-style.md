# Working style

Compact, universal interaction preferences — how output should be delivered, regardless of topic. Kept deliberately small since this loads on every turn; anything that isn't universal belongs in `user-patterns.md` instead.

- Prefers work saved as a file over code shown inline in chat.
- Wants scripts handed over ready to run, not just displayed for review.
- Change documentation (commit messages, PR descriptions, changelogs) follows a specific writing convention (referred to as the MCR pattern) — bring the actual convention over from the existing patterns file.

Add to this file only through the `patterns-consolidation` skill, once a preference has been confirmed as standing (stated directly, or reinforced across sessions) — not on a single observation.
